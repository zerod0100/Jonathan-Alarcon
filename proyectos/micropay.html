Microservicios Orquestados en AWS

Migración de una aplicación monolítica hacia una arquitectura basada en microservicios utilizando servicios administrados de AWS.

📌 Descripción

MicroPay es una aplicación fintech utilizada como caso de estudio para implementar una arquitectura de microservicios orientada a mejorar la escalabilidad, disponibilidad y desacoplamiento de los componentes de la aplicación.

La solución separa las funcionalidades principales en dos servicios independientes: Usuarios y Pagos.

Cada microservicio se ejecuta como un contenedor Docker desplegado mediante Amazon ECS con AWS Fargate.

03

Servicios AWS utilizados

☁️ Amazon ECS

Orquestación y ejecución de los contenedores mediante AWS Fargate.

📦 Amazon ECR

Almacenamiento de las imágenes Docker de los microservicios.

🌐 API Gateway

Punto de entrada para las solicitudes hacia los servicios.

⚖️ Application Load Balancer

Distribución de solicitudes hacia los microservicios.

📊 CloudWatch

Registro y supervisión básica de los servicios.

🐳 Docker

Contenerización de las aplicaciones de Usuarios y Pagos.

04

Resultados

La implementación permitió separar las funcionalidades de la aplicación en servicios independientes, facilitando su despliegue y administración.

Los microservicios fueron ejecutados correctamente sobre ECS Fargate y las imágenes de los servicios fueron almacenadas en Amazon ECR.

API Gateway permitió establecer un punto de entrada para las solicitudes, mientras que Application Load Balancer gestionó el enrutamiento hacia los servicios correspondientes.

Finalmente, Amazon CloudWatch permitió revisar los registros generados por los contenedores y validar el funcionamiento de los servicios.
