Cloud Secure

Seguridad Cloud para Blue Wave

Proyecto de implementación de medidas básicas de seguridad cloud para la fintech Blue Wave, utilizando recursos disponibles en AWS Academy Learner Lab.

La solución busca reforzar la protección de datos, la auditoría de eventos, la evaluación de cumplimiento y el monitoreo del entorno cloud.

El proyecto aplica el principio de mínimo privilegio como parte de las medidas básicas de seguridad.

1. Protección de datos con Amazon S3

Se configuró un bucket de Amazon S3 destinado a proteger la información almacenada por Blue Wave y evitar una exposición pública.

La configuración contempla ACLs deshabilitadas, manteniendo al propietario del bucket como responsable de los objetos.

También se habilitaron las cuatro opciones de Block Public Access y el cifrado predeterminado SSE-S3.

2. Auditoría con AWS CloudTrail

AWS CloudTrail se configuró para registrar las acciones realizadas dentro de la cuenta AWS, proporcionando trazabilidad para las operaciones del entorno.

El trail utilizado en el proyecto se identifica como:

blue-wave-security-trail

Los eventos de administración son almacenados en Amazon S3 para facilitar posteriormente su revisión y auditoría.

3. Cumplimiento con AWS Config

AWS Config permite registrar los recursos seleccionados y evaluar continuamente su configuración mediante reglas de cumplimiento.

Para el proyecto se configuró AWS Config utilizando el rol administrado por el servicio y un bucket S3 destinado al almacenamiento de información de configuración e historial.

Se incorporó una regla relacionada con la exposición pública de buckets S3.

Rule: s3-bucket-public-read-prohibited

Compliance: COMPLIANT

4. Monitoreo con Amazon CloudWatch

Amazon CloudWatch se utilizó para proporcionar visibilidad operacional sobre los recursos utilizados por la solución.

Se configuró una alarma para monitorear la cantidad de objetos almacenados en el bucket de Amazon S3.

Resultado del monitoreo

La alarma BlueWave-S3-NumberOfObjects permite detectar un crecimiento en la cantidad de objetos almacenados cuando se supera el umbral configurado de 100 objetos.

Esto proporciona una señal de alerta para identificar cambios importantes en el almacenamiento y facilitar acciones preventivas.

Conclusiones

La implementación de AWS Config permitió automatizar la evaluación de la postura de seguridad de los recursos de Blue Wave, utilizando estados de cumplimiento como COMPLIANT y NON_COMPLIANT.

La integración de Amazon CloudWatch mediante alarmas métricas proporciona visibilidad operacional sobre el crecimiento de los datos almacenados.

La configuración de Amazon S3 con bloqueo de acceso público y cifrado contribuye a reducir el riesgo de exposición de la información.
