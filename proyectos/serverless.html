Serverless Inteligente

Arquitectura Serverless para CloudCommerce

Descripción

Implementación de una arquitectura serverless para una aplicación de comercio electrónico, utilizando servicios administrados de AWS.

El proyecto busca reducir la dependencia de servidores tradicionales y construir una solución escalable y de bajo acoplamiento.

Servicios AWS utilizados

Amazon S3: alojamiento del sitio web estático.

AWS Lambda: ejecución de funciones para usuarios y pedidos sin administrar servidores.

Amazon API Gateway: exposición de las operaciones mediante endpoints HTTP.

Amazon DynamoDB: almacenamiento NoSQL de los pedidos.

Amazon CloudWatch: supervisión y revisión de los registros de ejecución de las funciones Lambda.

Aprendizajes

El proyecto permitió aplicar conceptos de arquitectura serverless, integración de servicios cloud, APIs y bases de datos NoSQL.

También permitió comprender cómo separar responsabilidades entre servicios administrados y utilizar Lambda para ejecutar lógica de negocio bajo demanda.
