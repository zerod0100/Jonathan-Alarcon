Serverless Inteligente

Arquitectura Serverless para CloudCommerce

Descripción del proyecto

Implementación de una arquitectura serverless para una aplicación de comercio electrónico, utilizando servicios administrados de AWS.

El proyecto busca reducir la dependencia de servidores tradicionales y construir una solución escalable, flexible y de bajo acoplamiento.

La solución utiliza servicios administrados para separar la presentación, la lógica de negocio, las APIs y el almacenamiento de datos.

Servicios AWS utilizados

Amazon S3: alojamiento del sitio web estático y distribución de los archivos de la aplicación.

AWS Lambda: ejecución de funciones para procesar las operaciones de usuarios y pedidos sin administrar servidores.

Amazon API Gateway: exposición de las operaciones mediante endpoints HTTP que permiten comunicarse con las funciones Lambda.

Datos y monitoreo

Amazon DynamoDB: almacenamiento NoSQL utilizado para gestionar la información de los pedidos.

Amazon CloudWatch: supervisión de la ejecución de las funciones Lambda mediante registros y logs.

Python: lenguaje utilizado para implementar la lógica de las funciones serverless.

Aprendizajes

El proyecto permitió aplicar conceptos de arquitectura serverless, integración de servicios cloud, desarrollo de APIs y utilización de bases de datos NoSQL.

También permitió comprender cómo separar responsabilidades entre servicios administrados y utilizar AWS Lambda para ejecutar lógica de negocio bajo demanda.

La experiencia permitió reforzar conocimientos sobre escalabilidad, desacoplamiento y monitoreo dentro de una arquitectura cloud.

Resultado

Se diseñó una solución orientada a servicios administrados de AWS, reduciendo la necesidad de mantener infraestructura de servidores y permitiendo que los componentes puedan escalar de acuerdo con la demanda.
